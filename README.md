## Reflexión sobre el funcionamiento del sistema

### 1. ¿Qué pasó con los pedidos del día cuando cerramos y volvimos a abrir el programa?

Cuando cerramos el programa y lo volvimos a abrir, los pedidos registrados durante el día se perdieron. Esto sucede porque la información se guarda temporalmente en la memoria del programa y no en una base de datos o archivo permanente. Por eso, al cerrar el programa, los datos dejan de estar disponibles.

### 2. Si Domi abre una segunda sede con otro operador, ¿cómo compartirían los clientes y los pedidos entre las dos?

Para compartir la información entre las dos sedes, podríamos utilizar una base de datos centralizada donde se almacenen todos los clientes y pedidos. Así, los dos operadores podrían consultar y registrar información desde diferentes lugares, manteniendo los datos actualizados y evitando que cada sede tenga información independiente.

Además, cada pedido podría identificar la sede donde fue registrado para facilitar su organización y seguimiento.
